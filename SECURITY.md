# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub's private vulnerability reporting for this repository](https://github.com/arifahmedjoy/lean-token/security/advisories/new).
Include the affected version or commit, the impact, and steps to reproduce when
safe to do so. Do not open a public issue for an unpatched vulnerability.

If private reporting is unavailable, contact the repository maintainers through
GitHub and request a private channel. Please allow maintainers reasonable time
to investigate and prepare a fix before public disclosure.

## Scope

Reports are most useful when they demonstrate a security impact in LeanToken
itself. Avoid submitting secrets, private transcripts, or third-party data.
